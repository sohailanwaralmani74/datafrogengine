# DataFrog — Browser-Based Data Intelligence Workspace

Welcome to **[DataFrog](https://datafrog.tools/)** — a privacy-first, client-side data intelligence workspace for software engineers, data professionals, and analysts. DataFrog offers an expanding suite of specialized data tools organized across core operational categories (**Inspect**, **Analyze**, **Validate**, **Compare**, and **Visualize**).

All processing executes 100% locally inside your browser memory — **zero server uploads, zero remote logging, zero paywalls, and fully offline-capable once loaded**.

---

## 🌐 Platform Architecture & Core Categories

DataFrog tools are structured into five primary data intelligence modules:

### 🔍 Inspect
Deep data structure viewers, tree formatters, raw decoders, multi-sheet spreadsheet inspectors, and node path finders for JSON, CSV, XML, YAML, Excel, and structured files.

### 📊 Analyze
Statistical summary engines, column profilers, numeric metrics (mean, median, min, max, sum), data type distribution calculators, missing value ratio analyzers, and log error auditors.

### ✅ Validate
Syntax checkers, line & column error detectors, schema constraint verifiers (including JSON Schema Draft-04, Draft-07, and 2020-12), delimiter auditors, and structural compliance tools.

### ⚖️ Compare
Side-by-side and inline structural diffing utilities, key path comparators, tabular cell modification highlighting engines, and change audit report exporters.

### 📈 Visualize
Interactive visual tree node diagrams, multi-sheet spreadsheet dashboards, searchable data tables, and high-resolution chart generators (Bar, Line, Pie, Doughnut).

*New tools and format converters are continuously added to the workspace.*

---

## 🔒 Privacy & Security First

- **100% Client-Side Execution**: All parsing, diffing, validation, and charting run directly in local browser RAM using Web APIs.
- **Zero Server Uploads**: Your files, sensitive payloads, and data streams never leave your local machine.
- **Offline Capable**: Once loaded in your browser, DataFrog tools operate seamlessly without an active internet connection.
