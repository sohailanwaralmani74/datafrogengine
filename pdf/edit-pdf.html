Edit PDF files without uploading them

This PDF editor works in your browser. You can change supported existing text, add new text, cover visible content, rotate pages, delete pages, and save the result as a new PDF.

What can I edit in a PDF?

PDF files store text, images, graphics, fonts, forms, annotations, and page structure in different ways. This editor changes the parts it can safely understand instead of pretending every PDF element is ordinary editable text.

Why might some PDF text not be editable?

Some PDFs use embedded fonts, unusual character mappings, outlined text, scanned pages, or content structures that do not contain ordinary editable text. When the browser editor cannot safely rewrite a text run, it leaves it unchanged.

Is this PDF editor private?

Yes. The selected PDF is processed in your browser. The file is not uploaded to a server for editing.

Frequently asked questions

How do I edit a PDF?

Choose a PDF, select a page, then change supported existing text, add text, cover visible content, rotate a page, or delete a page. Download the edited PDF when you are finished.

Can I edit existing text in a PDF?

Yes, when the text is stored as a compatible PDF text run. The editor changes the PDF text content instead of simply placing replacement text over the original.

Can I edit a scanned PDF?

Scanned PDFs usually contain page images rather than editable text. You can still add text and make page-level changes, but changing text inside the scan requires OCR.

Does this PDF editor upload my file?

No. The PDF is processed in your browser and is not uploaded to a server by this editor.

Why can't I change some text?

Some PDF text uses character encodings or structures that cannot be safely rewritten. The editor leaves unsupported text unchanged rather than corrupting the document.

Can I add text to a PDF?

Yes. Enter the text, choose its page position and size, and add it to the PDF.

Can I delete a PDF page?

Yes. Select the page and choose Delete page. The edited PDF is rebuilt with the remaining pages.

Can I rotate a PDF page?

Yes. Select a page and choose Rotate 90°. The page rotation is stored in the PDF itself.
