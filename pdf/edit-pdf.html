Edit PDF directly on the page

This editor renders the PDF page in your browser and places selectable text regions over the document. Click a supported text run to change it, add new text by clicking the page, or cover visible content with a drawn rectangle.

Why can some PDF text not be edited?

PDF text can use embedded fonts, unusual character mappings, outlined glyphs, or other structures. Scanned pages contain pixels rather than editable text. When the underlying text cannot be safely rewritten, the editor leaves it unchanged.

Is the PDF uploaded?

No. The selected PDF is read and processed in your browser. It is not uploaded for editing.

About covers and redaction

A white cover hides visible content but does not securely remove the underlying PDF content. Do not use this tool as secure redaction.

Frequently asked questions

Can I edit existing PDF text?

Yes, supported PDF text runs can be selected directly on the page and replaced.

Can I add text anywhere?

Yes. Choose Add text, enter the text, click Place text, then click the desired location on the PDF page.

Can I edit a scanned PDF?

Scanned PDFs usually contain images rather than text. Changing text inside the scan requires OCR.

Can I rotate or delete pages?

Yes. Use the toolbar controls while the page is selected.

Does this editor upload my PDF?

No. PDF processing takes place in your browser.
