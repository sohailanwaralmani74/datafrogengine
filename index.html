EXCEL • CORE

Workbook & Sheet Hierarchy

EXCEL • FORMULAS

Formula Expression Engine

Recursive-descent expression parser supporting arithmetic, comparisons, string concatenation, and built-in functions: SUM, AVERAGE, MIN, MAX, COUNT, IF, ROUND, and cross-sheet references.

EXCEL • STYLING

StyleSheet & Formatting

OpenXML styles manager for custom fonts, solid/pattern fills, multi-weight borders, horizontal/vertical alignments, text wrapping, and ISO number formats (currency, percentages, dates).

EXCEL • OPENXML

ZIP & OpenXML Serialization

In-memory ZIP archive engine with IEEE 802.3 CRC-32 checksums, Deflate compression, shared strings tables (SST), relationship maps, and XML builders for 100% compliant .xlsx files.

EXCEL • INTEROP

CSV, JSON & HTML Tables

Import and export data seamlessly. Load workbooks directly from CSV with auto-type casting, export to 2D arrays, structured JSON objects with header keys, or styled HTML <table> elements.

EXCEL • BUILDER

Declarative Report Builder

Fluent ExcelBuilder API for rapid reporting: branding headers, styled banner titles, auto-fitted table columns, zebra-striped data rows, and automated total calculation rows.

PDF • CORE

Lexer & Object Parser

Tokenizes arbitrary binary streams. Handles standard PDF objects: Dictionaries, Arrays, Indirect References (R), Hex Strings, Name objects, Booleans, and Real numbers.

PDF • STREAMS

Filter Decompression

Chained multi-stage decoders including FlateDecode, ASCIIHexDecode, ASCII85Decode, RunLengthDecode, and LZW with TIFF/PNG horizontal and vertical predictor inversion.

PDF • INDEXING

Cross-Reference Tables

Locates startxref from EOF, parses classic table sections, handles multi-generation free/in-use entries, and parses modern compressed Cross-Reference Streams.

PDF • FONTS

Typography & Metrics

Standard 14 PDF font metrics (Helvetica, Times, Courier, Symbol, ZapfDingbats) with character advance width tables, kerning, and automated line wrapping algorithms.

PDF • GRAPHICS

Vector Engine & Paths

Affine matrix transformation pipeline (scale, rotate, translate, skew). Constructs Bézier curves, straight paths, clipping paths, and fill/stroke operators.

PDF • SECURITY

Encryption & Metadata

Standard 40-bit and 128-bit encryption handlers, user/owner password authentication, permissions dictionaries, and full trailer /Info metadata serialization.

XML • DOM TREE

W3C DOM & Tokenizer

Full DOM Level 3 compliant node graph: XmlDocument, XmlElement, XmlText, XmlCData, XmlComment, and XmlProcessingInstruction with line/column diagnostic tracking.

XML • QUERIES

XPath & CSS Selectors

Query document nodes effortlessly via querySelector and querySelectorAll, or evaluate XPath 1.0 expressions including deep axis //tag, predicates [@attr="val"], and positional indexing.

XML • JSON BRIDGE

Bidirectional XML ↔ JSON

Seamless interoperability between XML documents and JavaScript objects. Automatic array aggregation, configurable attribute prefixes (@attr), automatic type coercion, and fluent programmatic XmlBuilder.

JSON • CONVERTERS

Multi-Format Data Converters

Bi-directional, zero-loss transformation between JSON and XML, CSV, YAML, NDJSON, Microsoft Excel (.xlsx), and styled PDF data reports with automatic header inference and delimiter auto-detection.

JSON • EDITORS

Path Editor & RFC 6902 Patch

Dot-notation & JSON Pointer path navigation (get, set, delete), full RFC 6902 JSON Patch engine (applyPatch, createPatch), object flattening/unflattening, key renaming, and deep merge.

JSON • VALIDATORS

Diagnostic Validator & JSON Schema

High-precision syntax validation with line/column pointers and visual code snippets. Complete JSON Schema Draft-07 validator supporting types, ranges, regex patterns, formats (email, uuid, uri, date), and required fields.

JSON • ANALYZERS

Structural Profiler & Schema Inferer

Profiles byte sizes (raw, formatted, gzipped estimate), total nodes, max depth, type distribution, and anomaly detection. Automatically synthesizes ready-to-use JSON Schema Draft-07 contracts from arbitrary datasets.

JSON • INSPECTORS

Diff Inspector & JSONPath Queries

Deep structural diffing comparing additions, removals, and value/type modifications across documents. JSONPath query engine evaluating deep descent $..price, wildcards, and filter expressions [?(@.active)].

JSON • CLEANERS

Sanitizer, Minifier & Auto-Repair

Auto-heals malformed JSON by stripping JS comments (//, /* */), fixing single quotes, quoting bare keys, and stripping trailing commas. Cleans nulls, empty strings/arrays, trims values, and normalizes key ordering.
