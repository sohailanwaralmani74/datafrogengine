Advanced Data Transformation

RFC 6902 JSON Patch

Generate precise delta patches between two documents and atomically apply patch sets across complex objects.

JsonEngine.createPatch(docA, docB)

Schema Inference & Anomaly Detection

Infer JSON Schema definitions automatically and detect type shifts, outlier keys, and inconsistent collections.

JsonEngine.inferSchema(dataset)

Key Permutation & Reordering

Reorder keys based on priority arrays, sort keys recursively, and flatten/unflatten nested dictionaries.

JsonEngine.reorderKeys(obj, ['id', 'name'])

Self-Healing Repair

Heal malformed JSON strings containing trailing commas, unquoted keys, single quotes, or unclosed brackets.

JsonEngine.repair('{name: "Datafrog",}')

Interactive Code Example

import { JsonEngine } from '/assets/js/index.js';

const raw = `{ status: "ok", count: 12, details: { tags: ["prod", "us-east"], } }`;

// 1. Repair malformed JSON
const repaired = JsonEngine.repair(raw);
const parsed = JsonEngine.parse(repaired);

// 2. Query with JSONPath
const tags = JsonEngine.query(parsed, '$.details.tags[*]');

// 3. Infer Schema & Diff
const schema = JsonEngine.inferSchema(parsed);
const diff = JsonEngine.diff({ count: 10 }, parsed);
console.log('Differences:', diff.differences);
