XML Architecture & Capabilities

Streaming SAX & DOM

Stream massive XML feeds using lightweight event callbacks or construct full DOM trees with namespaces.

XmlEngine.saxParser(xmlString, handlers)

XPath & CSS-Style Selectors

Query nodes by tag names, attribute values, and child paths with full attribute mutation capabilities.

XmlEngine.xpath(doc, '//item[@id="10"]')

Child Permutation & Reordering

Reorder child tags, rename tag names, strip comments, and eliminate whitespace noise.

XmlEngine.reorderChildren(doc, 'root', ['b', 'a'])

Bi-directional JSON Bridge

Convert XML structures directly into compact JSON objects and re-serialize JSON trees into validated XML.

XmlEngine.toJson(xmlString)

Interactive Code Example

import { XmlEngine } from '/assets/js/index.js';

const xml = `<catalog><book id="bk101"><title>Datafrog Manual</title><price>44.95</price></book></catalog>`;

// 1. Parse into DOM tree
const doc = XmlEngine.parse(xml);

// 2. Query nodes
const book = XmlEngine.query(doc, 'book');
XmlEngine.setAttribute(book, 'status', 'active');

// 3. Convert to JSON
const json = XmlEngine.toJson(xml);
console.log('Converted JSON:', json);
